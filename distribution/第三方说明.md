# 第三方组件与分发内容

本包分发 MotionVfx Live 的后台、Lua、MCP、输入插件、运行环境和对应源码。游戏、游戏或 MOD 特效素材、PAK、解包样本、用户输出与机器路径配置不包含在原始发布包内。REFramework 为单独安装的运行前提。

| 组件 | 来源与用途 | 许可文件 |
|---|---|---|
| ReeLib / RE-Engine-Lib 代码及修改 | 原项目提供的 RE-Engine-Lib，EFX 解析与写入；copyright 2025 shadowcookie | `licenses/ReeLib-MIT.txt` |
| ZstdSharp.Port 0.8.5 | https://github.com/oleg-st/ZstdSharp，PAK 解压 | `licenses/ZstdSharp-MIT.txt` |
| Standart.Hash.xxHash 4.0.5 | https://github.com/uranium62/xxHash，资源路径哈希 | `licenses/xxHash-MIT.txt` |
| Microsoft .NET 10.0.8 Windows x64 | 自包含程序运行环境 | `licenses/dotnet-LICENSE.TXT`、`licenses/dotnet-THIRD-PARTY-NOTICES.TXT` |
| Microsoft Windows Desktop 10.0.8 Windows x64 | 安装器及录制辅助程序的自包含桌面运行环境 | `licenses/dotnet-desktop-LICENSE.txt` |
| REFramework D2D 1.4.1 | 游戏内 Direct2D 界面、图像与文字绘制 | `licenses/REFramework-D2D-LICENSE.txt` |
| REasy Wilds RSZ 类型定义 | https://github.com/seifhassine/REasy；采用匹配当前角色 PFB 的 FootLandingCustomData.Element 定义 | `licenses/REasy-LICENSE.txt` |
| Lua 5.4.3 / REFramework API 1.15 头文件 | MotionVfxDebugInput.dll 的 Lua 接口与插件回调 | `licenses/MotionVfxDebugInput-THIRD-PARTY.txt` |

在发行包中，C# 对应源码位于 `Source`，Lua 源码位于 `plugin`，输入 DLL 源码位于 `Source/tools/DebugInput`；源码仓库则保留各项目与 `game-plugin`、`tools/DebugInput` 目录。输入插件仅在游戏进程内处理键盘，不安装系统全局键盘钩子。构建时使用的 Roslyn 分析器为开发依赖，并未作为运行时组件分发。保留上述许可与声明再分发。包内没有捆绑作为参考的 Python 特效编辑插件或用户的 MOD 文件。
